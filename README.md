## 🚀 آموزش نصب و راه‌اندازی DegerisBot

**نصب DegerisBot از طریق یک نصب‌کننده تحت وب انجام می‌شود.**

برای نصب اولیه نیازی به اجرای دستی دستورات پیچیده ندارید و تمام مراحل اصلی از طریق مرورگر قابل انجام است.

### مرحله ۱: دانلود سورس

ابتدا سورس پروژه DegerisBot را از مخزن گیت‌هاب دریافت کنید.

### مرحله ۲: آپلود سورس روی هاست

فایل ZIP دانلودشده را در مسیر اصلی هاست خود، معمولاً `public_html`، آپلود کرده و سپس آن را از حالت فشرده خارج کنید.

### مرحله ۳: ورود به صفحه نصب

پس از آپلود و استخراج کامل فایل‌ها، مرورگر خود را باز کنید و آدرس دامنه را به همراه مسیر `/install` وارد کنید.

**مثال:**

`https://your-domain.com/install`

به‌جای `your-domain.com` دامنه خودتان را قرار دهید.

پس از ورود به این آدرس، صفحه نصب DegerisBot نمایش داده می‌شود.

### مرحله ۴: وارد کردن اطلاعات

در صفحه نصب، اطلاعاتی که سیستم از شما درخواست می‌کند را وارد کنید. این اطلاعات شامل موارد زیر است:

- توکن ربات تلگرام (Bot Token)
- شناسه عددی مدیر اصلی (Admin ID)
- دامنه ربات
- اطلاعات اتصال به دیتابیس
- فایل بکاپ، در صورت نیاز به بازیابی اطلاعات قبلی

### مرحله ۵: شروع فرآیند نصب

پس از تکمیل اطلاعات، روی دکمه **«نصب»** کلیک کنید.

نصب‌کننده به‌صورت خودکار مراحل راه‌اندازی، آماده‌سازی دیتابیس و اجرای عملیات موردنیاز را انجام می‌دهد.

### مرحله ۶: پایان نصب

پس از نمایش پیام نصب موفقیت‌آمیز، ربات شما آماده راه‌اندازی و استفاده خواهد بود.

### 🔄 نصب همراه با بازیابی بکاپ

اگر قصد مهاجرت از MirzaBot یا بازیابی بکاپ قبلی را دارید، می‌توانید در صفحه نصب، فایل بکاپ مربوطه را در قسمت مخصوص وارد کنید.

مراحل به این صورت است:

1. از دیتابیس ربات قبلی بکاپ تهیه کنید.
2. سورس DegerisBot را روی هاست آپلود کنید.
3. وارد آدرس `/install` شوید.
4. اطلاعات موردنیاز نصب را تکمیل کنید.
5. فایل بکاپ MirzaBot یا DegerisBot را انتخاب کنید.
6. نصب و بازیابی اطلاعات را تأیید کنید.
7. منتظر بمانید تا عملیات Restore و Migration تکمیل شود.

پس از اتمام عملیات، اطلاعات منتقل‌شده را بررسی کنید.

### 📋 پیش‌نیازهای نصب

| مورد | نیازمندی |
|---|---|
| ⚙️ زبان برنامه‌نویسی | PHP 8.2 یا بالاتر |
| 🗄️ دیتابیس | MySQL 8 یا MariaDB |
| 🌐 وب‌سرور | Apache یا Nginx |
| 🔒 گواهی SSL | HTTPS فعال |
| 🌍 دامنه | دامنه متصل به هاست |
| 🤖 ربات تلگرام | توکن دریافتی از BotFather |
| 👤 مدیریت | شناسه عددی مدیر اصلی |

### ⚠️ نکات مهم نصب و بازیابی

- پیش از نصب، از اطلاعات قبلی خود بکاپ تهیه کنید.
- اطلاعات دیتابیس را با دقت وارد کنید.
- دامنه باید به هاست متصل باشد.
- گواهی SSL معتبر و HTTPS فعال باشد.
- در صورت بازیابی بکاپ، از دیتابیس مقصد نسخه پشتیبان داشته باشید.
- عملیات Restore ممکن است تمام جداول و اطلاعات قبلی دیتابیس مقصد را حذف و مجدداً ایجاد کند.
- پس از نصب موفق، پوشه `install/` را از هاست حذف کنید.
